# Publish Helper 2.0 使用指南

> PT（Private Tracker）资源发布助手 —— 把发种前的简介抓取、截图、图床上传、智能命名、制种、Auto-Feed 一键填表等繁琐步骤自动化。
> 支持 **电影 / 剧集 / 短剧** 三类内容，提供 **GUI / API / CLI** 三种运行形态。

---

## 1. 环境准备

### 1.1 运行环境
- Python **3.9+**（开发机已验证 3.12 / 3.13）
- 操作系统：Windows / macOS / Linux 均可

### 1.2 系统依赖（MediaInfo 解析库）
本项目使用 `pymediainfo` 提取视频信息，需要 `libmediainfo` 支持：

- **Windows / macOS**：无需手动安装，`pymediainfo` 已打包所需库文件（仓库内含 `libmediainfo.0.dylib`、`lib_deb/` 备用）。
- **Linux**：需手动安装

  ```bash
  # Debian/Ubuntu
  apt install libmediainfo0v5
  # CentOS/RHEL/Fedora
  dnf install libmediainfo
  # Arch Linux
  pacman -S libmediainfo
  ```

### 1.3 中文字体（仅 Linux 服务器）
若 Linux 上截图/界面中文显示为方块，请安装中文字体：

```bash
apt install fonts-noto-cjk   # 或 fonts-wqy-zenhei fonts-wqy-microhei
fc-cache -f -v
```

### 1.4 安装依赖
```bash
# 生产依赖
pip install -r requirements.txt

# 开发依赖（运行测试 / 代码检查时需要）
pip install -r requirements-dev.txt
```

## 2. 三种运行模式

> ⚠️ **注意入口文件名**：README 及 `docs/DEVELOPMENT.md` 中出现的 `main_gui_new.py` / `main_api_new.py` 在本仓库中并非当前实际使用的入口。**请一律使用根目录的 `main_gui.py` / `main_api.py` / `main_cli.py`**（仓库根目录 `src/` 下）。下文的命令均以实际文件为准。

### 2.1 GUI 模式（桌面图形界面）
适合个人日常使用，所有操作在窗口中完成。

```bash
python src/main_gui.py
```

启动后通过界面填写豆瓣/IMDB 链接、选择视频、配置截图与图床参数，点击按钮即可逐步或一键完成发布准备。

**Windows 打包为 exe**（在根目录执行，Python 3.10 + PyInstaller）：
```bash
pip install pyinstaller
pyinstaller --paths="src;." -F -w -i static/ph-bjd.ico src/main_gui.py -n "Publish Helper.exe"
xcopy static dist\static /E /I /Y
mkdir dist\media
mkdir dist\temp\pic
mkdir dist\temp\torrent
copy media\视频资源存放目录.txt dist\media\
copy temp\pic\默认图片目录.txt dist\temp\pic\
copy temp\torrent\默认种子目录.txt dist\temp\torrent\
copy Mandarin.dat dist\
copy LICENSE dist\  &&  copy README.md dist\  &&  copy readme.txt dist\
```

### 2.2 CLI 模式（交互式命令行）
适合在服务器 / 无界面环境使用，基于 `prompt_toolkit` 提供路径自动补全。

```bash
python src/main_cli.py
```

启动后为**交互式问答**流程，依次输入：
1. **内容类型** —— 电影 / 剧集 / 短剧（数字选择，或直接输入自定义）
2. **资源链接** —— 豆瓣 / IMDB 的 URL
3. **季数（Season）** —— 剧集/短剧需要，默认 `1`
4. **视频路径** —— 文件或文件夹路径（支持 Tab 补全）

确认后程序自动完成：PT-Gen 简介抓取 → MediaInfo 解析 → 截图/缩略图 → 图床上传 → 智能命名/重命名 → 制种 → 生成 Auto-Feed 一键填表链接。

> CLI 模式支持「只制作种子」子流程：在制种阶段可单独生成 `.torrent` 而不依赖其他步骤。

### 2.3 API 模式（REST 服务）
适合二次开发、与前端/其他系统对接，或 Docker 部署。

```bash
python src/main_api.py
```

- 基于 Flask，**绑定 `0.0.0.0`**
- **端口由 `static/settings.json` 的 `api_port` 字段控制**（默认 `"15372"`，非环境变量）
- 默认开启 `debug=True`，并支持跨域（CORS）

健康检查可访问：`http://<host>:<api_port>/`

## 3. API 接口列表

所有接口基址为 `http://<host>:<api_port>`。除特别说明外，参数通过 **URL query string** 传递。

### 3.1 信息查询类（GET）

| 接口 | 说明 | 主要参数 |
|---|---|---|
| `/api/getMediaInfo` | 获取 MediaInfo 文本 | `path`（限 `media/` 下） |
| `/api/getVideoInfo` | 获取视频关键参数（编码/色深/HDR/帧率/音轨等） | `path` |
| `/api/getScreenshot` | 按百分比区间截图（默认 ≤5 张，可设去黑场阈值） | `path`、`screenshotNumber`、`screenshotStartPercentage`、`screenshotEndPercentage`、`screenshotThreshold` |
| `/api/getThumbnail` | 生成缩略图拼图 | `path`、`thumbnailRows`、`thumbnailCols`、`screenshotStartPercentage`、`screenshotEndPercentage` |
| `/api/getPtGenDescription` | 根据豆瓣/IMDB 链接获取 PT-Gen 简介 | `resourceUrl`（`auto_download_upload_poster` 开启时自动上传海报） |
| `/api/getPtGenInfo` | 从简介文本中解析标题/年份/演员等 | `description` |
| `/api/getPTGenInfoByResourceUrl` | 链接直达：解析简介并返回结构化字段 | `resourceUrl` |
| `/api/getPlayletDescription` | 获取短剧简介 | `originalTitle`、`year`、`area`、`category`、`language`、`seasonNumber` |
| `/api/getNameFromTemplate` | 根据模板名 + 字段生成命名 | `template`（见下）、`englishTitle`、`originalTitle`、`year`、`videoCodec`、`hdrFormat`、`audioCodec` 等 |
| `/api/getTotalEpisode` | 统计文件夹内集数描述 | `folderPath`、`episodeStartNumber` |
| `/api/getComboBoxData` | 读取 `source`/`team`/`playlet-source` 下拉数据 | `configurationName` |
| `/api/getSettings` | 读取单个配置项 | `settingsName` |
| `/api/settings` | 返回完整 `settings.json` | — |
| `/api/media/file/list` | 列出 `media/` 目录文件 | `path` |

> `getNameFromTemplate` 的 `template` 取值：`main_title_movie` / `main_title_tv` / `main_title_playlet` / `second_title_movie` / `second_title_tv` / `second_title_playlet` / `file_name_movie` / `file_name_tv` / `file_name_playlet`。

### 3.2 写操作类（POST）

| 接口 | 说明 | 主要参数 |
|---|---|---|
| `/api/uploadPicture` | 本地图片上传到图床 | `picturePath`、`pictureBedApiUrl`、`pictureBedApiToken` |
| `/api/makeTorrent` | 制作 `.torrent` 种子 | `path`、`torrentStoragePath` |
| `/api/renameFile` | 重命名文件 | `filePath`、`newFileName` |
| `/api/renameFolder` | 重命名文件夹 | `folderPath`、`newFolderName` |
| `/api/renameEpisode` | 剧集批量重命名 | `folderPath`、`newFileName`、`episodeStartNumber` |
| `/api/createHardLink` | 创建硬链接 | `path` |
| `/api/moveFileToFolder` | 移动文件到指定文件夹 | `filePath`、`folderName` |
| `/api/updateComboBoxData` | 更新下拉数据 JSON | `configurationName`、`configurationData` |
| `/api/updateSettings` | 更新单个配置项 | `settingsName`、`settingsData` |
| `/api/settings/update` | 批量更新整个 `settings.json` | JSON body |
| `/api/getFile` | 下载 `temp/` 下的种子/图片 | `filePath` |

### 3.3 一键处理（GET）

- `/api/autoHandleVideo` —— 一次性完成：简介抓取 → 命名 → 建目录/重命名/硬链接 → 制种 → Auto-Feed 链接。**必需参数**：`resourceUrl`、`path`、`source`、`team`、`category`；可选：`season`、`episodesStartNumber`。

> **安全限制**：API 模式下所有 `path` / `folderPath` / `filePath` 都会被强制解析到 `media/` 目录，越权访问返回 401。请提前把视频放进 `media/` 目录（仓库已提供 `media/` 占位）。

## 4. 配置说明

配置核心文件为 **`static/settings.json`**，支持通过 GUI、API（`updateSettings` / `settings/update`）或手动编辑修改。**无需 `.env` 文件**（README 提到的 `.env.example` 并非本仓库实际机制）。

### 4.1 主要配置项

| 配置项 | 含义 |
|---|---|
| `api_port` | API 监听端口（字符串，如 `"15372"`） |
| `enable_api` | 是否启用 API 模式（`"true"`/`"false"`） |
| `pt_gen_api_url` | PT-Gen 主 API 地址 |
| `pt_gen_api_url_backup` | PT-Gen 备用 API 地址 |
| `picture_bed_api_url` | 图床上传接口地址 |
| `picture_bed_api_token` | 图床 API Token（**敏感凭据，见下方安全提示**） |
| `screenshot_number` | 截图数量 |
| `screenshot_start_percentage` / `screenshot_end_percentage` | 截图起止百分比（0~1） |
| `screenshot_threshold` | 截图去黑场阈值 |
| `screenshot_storage_path` | 截图存储路径 |
| `do_get_thumbnail` | 是否生成缩略图拼图 |
| `thumbnail_rows` / `thumbnail_cols` | 缩略图拼图行列数 |
| `thumbnail_delay` | 缩略图去黑场延迟 |
| `auto_upload_screenshot` | 是否自动上传截图到图床 |
| `paste_screenshot_url` | 是否将截图 URL 写入简介 |
| `delete_screenshot` | 处理完成后是否删除本地截图 |
| `rename_file` | 是否重命名文件 |
| `make_dir` | 是否自动建立目录 |
| `create_hard_link` | 是否创建硬链接 |
| `second_confirm_file_name` | 重命名前是否二次确认 |
| `torrent_storage_path` | 种子文件存储路径 |
| `auto_feed_link` | 生成的 Auto-Feed 一键填表链接（程序产出） |
| `open_auto_feed_link` | 是否自动在浏览器打开该链接 |
| `auto_download_upload_poster` | 获取简介时是否自动下载海报并上传图床 |
| `personalized_signature` | 发布页个性化签名 |
| `media_info_suffix` | MediaInfo 文本后缀 |
| `main_title_movie` / `main_title_tv` / `main_title_playlet` | 主标题命名模板 |
| `second_title_movie` / `second_title_tv` / `second_title_playlet` | 副标题命名模板 |
| `file_name_movie` / `file_name_tv` / `file_name_playlet` | 文件名命名模板 |

### 4.2 命名模板变量
模板支持变量替换，常见占位符：`{title}`、`{english_title}`、`{year}`、`{video_format}`、`{source}`、`{video_codec}`、`{bit_depth}`、`{hdr_format}`、`{frame_rate}`、`{audio_codec}`、`{channels}`、`{audio_num}`、`{team}`、`{other_titles}`、`{season}`、`{total_episodes}`、`{category}`、`{actors}` 等。

### 4.3 安全提示
- **`picture_bed_api_token` 为明文凭据**，请勿提交到公开仓库；建议用 `git rm --cached static/settings.json` 移出版本控制，改用 `settings.example.json` 占位，敏感值通过本地文件或环境变量注入。
- API 无鉴权机制，部署到公网前务必用反向代理（Nginx）加认证/防火墙，且保持 `media/` 目录隔离。

## 5. 标准工作流（以电影为例）

无论哪种模式，底层流程一致：

1. **PT-Gen 简介**：输入豆瓣/IMDB 链接，抓取结构化影片信息。
2. **MediaInfo 解析**：提取编码、分辨率、色深、HDR、帧率、音轨、字幕。
3. **截图 + 缩略图**：按百分比区间取帧，可选黑场阈值过滤。
4. **图床上传**：把截图/海报上传到配置的图床，得到 BBCode / 直链。
5. **智能命名**：按模板生成主标题、副标题、文件名。
6. **文件整理**：建目录、重命名、硬链接（节省空间）。
7. **制种**：生成 `.torrent` 文件。
8. **Auto-Feed**：生成一键填表链接，可直接粘贴到 PT 站点发布页。

剧集/短剧额外包含集数统计（`getTotalEpisode`）、批量重命名（`renameEpisode`）等步骤。

## 6. Docker 部署

```bash
docker-compose up -d        # 构建并后台启动
docker-compose down         # 停止
```

- 镜像内已封装 `libmediainfo`、`nginx`，并通过 `lib_deb/entrypoint` 启动 API + Nginx。
- **端口映射**：`15372`（API）→ `15373`（Nginx）。注意：容器内 API 实际端口由 `static/settings.json` 的 `api_port` 决定，docker-compose 注入的 `API_PORT` 环境变量代码并未读取，请以 `settings.json` 为准。
- **数据卷挂载**：`./static`、`./media`、`./temp`、`./logs`，便于宿主机持续管理资源与配置。
- 构建镜像（研发）：`docker build -t publish-helper .`（见 `docs/docker_publish.md`）。

## 8. 常见问题

**Q：API 报「无权访问此文件 / UNAUTHORIZED_ACCESS_ERROR」？**
A：API 模式只允许访问 `media/` 目录下的资源，请把视频文件/文件夹放进 `media/` 再传相对路径。

**Q：Linux 截图/界面中文乱码？**
A：安装中文字体（见 1.3），执行 `fc-cache -f -v`。

**Q：运行 `main_api.py` 端口不对？**
A：检查 `static/settings.json` 的 `api_port`，代码以该值为准（不是 15372 环境变量）。

**Q：如何修改命名格式？**
A：编辑 `settings.json` 中的 `*_title_*` / `file_name_*` 模板，或通过 GUI 设置界面修改。

**Q：如何扩展图床 / 下拉选项？**
A：图床地址与 token 在 `settings.json`；`source` / `team` / `playlet-source` 下拉数据通过 `updateComboBoxData` 或对应 JSON 维护。
